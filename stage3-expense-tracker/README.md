# Stage Project · Personal Expense Tracker
A beginner-friendly Python project that helps users record, manage, filter, and report their personal expenses.

## Features
- Add expenses with amount, category, description, and date.
- Save expenses in a JSON file and load them automatically when the program starts.
- View all expenses in a table.
- Display total expenses by category.
- Filter expenses by month.
- Delete an expense.
- Export expense reports to CSV.
- Organize functionality across at least two Python modules.
- Handle invalid amounts and dates without crashing the program.

## Technologies Used
- Python
- JSON
- CSV
- `datetime` module
